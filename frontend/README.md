# 🖥️ RAGScript Frontend

Modern, high-performance web interface for the RAGScript codebase exploration platform.

## Features
- **Codebase Indexing:** Upload and index project repositories with local vector storage.
- **Natural Language Chat:** Context-grounded questioning with source citation panels.
- **Local-First Privacy:** Fast local state management and dark/light mode themes.

## Development Setup

```sh
cd frontend
npm install
npm run dev
```

The frontend connects directly to the FastAPI backend API at `http://localhost:8000`.
